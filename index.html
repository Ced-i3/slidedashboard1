Alert settings

Choose the limits checked against each fresh incoming reading.

Thresholds load when the station identity is available.
SLOPE POSITION

MPU angle thresholds

Each fresh reading is checked using the larger absolute pitch or roll angle. No calibration or Experimental Test mode is needed.

Angle = max(|pitch|, |roll|), relative to the sensor axes. A tilted installation may trigger immediately; there is no mounted baseline.

GROUND AND RAIN INPUTS

ADC thresholds

Set independent limits for the soil and rain sensors. Select the direction that matches your hardware.

ADC values range from 0 to 4095. These are raw counts, not wetness percentages or rainfall measurements.

HOW ALERTS WORK

Automatic monitoring in this browser

Fresh readings are checked against these limits. Normal readings clear the condition. Stale or unavailable readings pause evaluation and mark an active condition as unknown.

Settings are saved per station in this browser. Keep the dashboard open and connected to receive browser alerts. Browser alert history lasts for this page session.

S.L.I.D.E. reports experimental sensor conditions; it does not predict landslides.Station data unavailable
